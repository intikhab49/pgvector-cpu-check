# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise builds and code rather than people, and keep reports about
other projects' images factual and reproducible.

Report unacceptable behaviour by opening a private security advisory on this repository or by contacting the maintainer through their GitHub profile.
